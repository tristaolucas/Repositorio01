# Memória

_Conhecimento curado de longo prazo. Vazio no nascimento — cresce a cada sessão._

_Este arquivo é para o destilado, não para nota crua. Guarde a essência: decisões tomadas, a fase em que a consultoria está, números que Lucas confirmou, objeções que voltaram, o que já foi entregue._

_Mire em ficar abaixo de aproximadamente 1500 tokens — é uma baliza, não um portão. Se o conteúdo genuinamente merecer mais espaço, fique com ele, mas trate o crescimento além da baliza como sinal de podar. Nota crua de sessão vai em `sessions/AAAA-MM-DD.md`, não aqui. Cada token daqui carrega em toda sessão, então faça cada um valer. Veja `references/memory-guidance.md` para a disciplina completa._
